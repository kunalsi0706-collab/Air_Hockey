# 🏒 Air Hockey Game

A Python-based Air Hockey game project using computer vision and hand detection to create an interactive gaming experience.

## ✨ Features

- 🎮 Air Hockey gameplay
- 👋 Hand detection for interactive paddle control
- 🎯 Ball movement and collision detection
- 🧮 Score tracking
- 📷 Webcam-based interaction

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy

## 📁 Project Structure

```text
AirHockey/
├── main.py
├── utils/
│   ├── Ball.py
│   ├── Paddle.py
│   ├── Score.py
│   ├── collision.py
│   ├── constants.py
│   └── hand_detection.py
├── requirements.txt
├── .gitignore
└── README.md
```

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/kunalsi0706-collab/Air_Hockey.git
cd Air_Hockey
```

**2. Install the dependencies**

```bash
pip install -r requirements.txt
```

**3. Run the game**

```bash
python main.py
```

## 💻 Requirements

- Python installed on your computer
- Webcam, if required by the hand detection feature
- Required Python libraries
